🏆 sportEra
A web-based sports community platform that connects athletes, fans, and organizers. Users can register, post updates, view event listings, and upload images related to various sports.

📁 Project Structure
index.html – Home page

register.php, login.html, logout.php – Authentication

events.php, create-post.php, post-detail.php – Event and post management

upload/ – Folder containing user-uploaded images and media

connection.php – Database connection config

user.php, update-user.php – User profile handling

⚙️ Features
📝 User registration and login

📰 Post creation and sharing

📸 Upload and display sports images

🎯 Sports categories like Cricket, Kabaddi, Badminton, Hockey, etc.

💬 Community engagement through posts🧰 Tech Stack
Frontend: HTML, CSS, JavaScript

Backend: PHP

Database: MySQL

Server: XAMPP / Apache
